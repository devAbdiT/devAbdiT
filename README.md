### 👨‍💻 About Me

I'm a **Frontend Developer** passionate about building fast, accessible, and type-safe web applications. I focus on the **React ecosystem** — turning complex requirements into seamless user experiences.

- **Current Focus:** Masterfully implementing **Next.js** features like App Router, Server Components, and optimized data fetching.
- **The TypeScript Edge:** I write strictly typed code to ensure reliability, scalability, and a better developer experience.
- **State & Data:** Managing complex app state with **Redux Toolkit**, and building real-time features with **Socket.IO**.
- **UI Systems:** Building accessible, consistent interfaces fast with **shadcn/ui** and Tailwind CSS.
- **Performance First:** I focus on Core Web Vitals, ensuring that every interface I build is as lean and fast as possible.
- **Responsive Design:** Crafting layouts that look and feel great on any device using modern CSS and **Tailwind CSS**.

> *"Building interfaces that feel simple — even when the systems behind them aren't."*
