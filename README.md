### 👨‍💻 About Me

I'm a Software Engineering student at Jimma University who loves building web interfaces that are clean, responsive, and easy to use. I like starting from a real problem, thinking about the people who face it, and turning it into something they can actually use. Most of my work is in **React and Next.js**, and I'm now learning backend development so I can build complete products, from the database all the way to the screen.

- **Currently deepening:** Next.js (App Router, Server Components, and data fetching)
- **Type safety:** I write strictly typed TypeScript so code stays reliable and easy to maintain
- **State and real-time:** Redux Toolkit for app state, Socket.IO for real-time features
- **UI systems:** shadcn/ui and Tailwind CSS for consistent, accessible interfaces, built quickly
- **Growing into backend:** Node.js, Prisma, and PostgreSQL/MongoDB, so I can build the full picture behind the interface
- **Performance:** I pay attention to Core Web Vitals so interfaces stay lean and fast
- **Responsive design:** layouts that work well on any screen size
- **Looking for:** a frontend internship where I can contribute to meaningful projects, learn from experienced teammates, and keep growing as a developer

> *"Building interfaces that feel simple, even when the systems behind them aren't."*

#### 🏥 MediCare Cloud
A full-featured **Patient Management System** built for Jimma University Medical Center as a Community Based Training Program (CBTP) project.

- **What it does:** 10 modules and 6 user roles (including pharmacist and lab technician), with automatic invoicing, FIFO pharmacy stock, and a structured audit log
- **Built with:** Next.js (App Router), TypeScript, Prisma, PostgreSQL, Better Auth, Tailwind CSS, shadcn/ui
- **Links:** [Repository](https://github.com/devAbdiT/MediCare) • [Live demo](https://medi-care-tan-seven.vercel.app/)
